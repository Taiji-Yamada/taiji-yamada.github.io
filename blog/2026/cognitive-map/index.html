How to build a cognitive map (Whittington et al., 2022)

Created on November 04, 2026

2026   ·   hippocampus   learning to learn   cognitive map   state representation   ·   論文

書誌情報：Whittington, J. C. R., McCaffary, D., Bakermans, J. J. W., & Behrens, T. E. J. (2022). How to build a cognitive map. Nature Neuroscience, 25, 1257–1272. doi:10.1038/s41593-022-01153-y

一言でいうと

海馬体の様々なモデルを「多様な系列情報から環境の構造を潜在状態としてどう表現して般化に使うか」という共通の問題として整理したレビュー。

The cognitive mapping problem

認知地図が解くべき問題

  • 認知地図の目的は，事前の学習を可能な限り行い，オンラインでの学習や計算を最小限に抑えること。
  • モデルフリー強化学習はしばしば非柔軟であるが，モデルベース強化学習はツリーサーチなどの高い計算コストを要する。そこで，良い状態空間を構成することでこれを解決したい。
  • これを達成するためには，世界の構造に関する効率的な状態表現を獲得する必要がある。
    • 物理的空間では，各細胞が場所のIDを符号化するのではなく（場所細胞），座標表現（グリッド細胞）にする。
    • 物理的空間以外では，直感的ないい表現は決めづらい。そこで，空間をグラフ構造として表現する。

系列から潜在状態を予測する

  • グラフ表現を選んだはいいものの，どんなグラフを作ればよいか？
  • 感覚の観測をそのままノード（状態）にすべきではない。同じ観測は別の状況で起こるし，観測の結果は同じではない（エイリアシング，状態→観測は多対一，観測→状態は一対多）。世界は部分観測なので，潜在状態を推論する必要がある。
  • 観測の系列を使えばいい。実際，海馬体は系列から学び，潜在状態を表現している。
  • 潜在状態の推論とは，抽象空間での位置を知ることである。
    • 物理的空間では，経路積分をする。
    • 物理的空間以外でも，グラフ上では経路積分が使える（e.g., ボブはアリスの孫 ＋ クロエはボブの兄弟 → クロエはアリスの孫）。ただし，使えない場合もある。

状態表現を般化させる

  • グラフの知識を完全に移すのはNP困難。古いグラフのノードと新しいグラフのノードの完全な対応表が必要になる。
  • しかし，経路積分ならば容易。経路積分の表現は，特定のノード名に結びついた関係規則（Aの隣はB）ではなく，動き方の規則（東に＋1）だからどのノードでも成り立つ。
  • 海馬の表現自体は般化しないが，嗅内皮質の表現は般化する。
    • 海馬の場所細胞は，環境が変わると，発火する場所をバラバラに変える（remapping）。
    • 嗅内皮質のグリッド細胞は，環境が変わると，モジュール全体の格子がまとめてずれたり回転したりするが，同モジュール（格子の間隔と向きがほぼ同じで，位相，つまり格子の網目がどこにずれているかだけが違う）内の隣接するグリッド細胞は他の環境においても位相関係が保たれる（realignment）。
  • 般化の学習は，多くの環境にまたがる系列学習である。1つの系列だけなら，それは個別の事象として丸暗記できる。複数の系列を観測することで関係規則として学習が可能になる。
  • 般化を適用するには，抽象的な知識を具体的な予測にしなければならない（e.g., 「東に＋1で○○」の○○を予測する）。海馬の細胞がこの相互作用を反映しており，内側嗅内皮質（MEC）からの抽象的な知識と外側嗅内皮質（LEC）からの感覚的知識が海馬内で統合される。

Composition

  • 地図全体ではなく，部品を般化させることもできる（e.g., 形状の異なる部屋は，基礎となる2次元空間とどこにでも配置可能な壁で理解できる）。
  • 認知地図がタスクを横断する共通の構造的要素を表現していれば，これらの要素を組み合わせて，任意のタスク構成を理解できる。
  • 任意の構成を促進するためには，異なる構造要素（基底）を互いに独立して（因子分解して）表現する必要がある。そうすることで，タスクの理解は構造的推論問題，すなわち現在のタスクを表現するための適切な基底を見つける問題となる。
  • 海馬体の認知地図には，多くの基底表現が含まれている。
    • 局所的な基底：オブジェクト・ベクトル細胞，境界・ベクトル細胞，報酬細胞，目標・ベクトル細胞。これらは位置に関係なくあらゆる物体・境界・目標を符号化する局所的な基底表現である。
    • 大域的な基底：グリッド細胞は，空間全体にわたって均一に情報を記述するため，大域的な基底である。

New interpretations, integrations and predictions

非空間的海馬細胞は，般化のための潜在状態表現である

  • 海馬には非空間を表す細胞が多くあるが，どれも2つの原理だけで説明できる。
    • disambiguation：同じ場所でも，その先の展開が違えば別の状態として区別する（潜在状態）。
    • generalization：空間として同じであることは共有し，使い回す。
  • 効率的な般化には，あらゆる抽象化レベルを同時に表現しなければならない。空間的課題では空間を，非空間的課題では非空間を，空間と非空間が相互作用する課題ではその両方を表現する必要がある。T-mazeを左右交互に進む課題では，左→中央→右→中央における2つの中央の意味は違う。しかし，これだけでは中央は同じ場所だという情報がなく，1回目の中央での観測を2回目に使い回せない。スプリッター細胞と場所細胞がそれにあたる。

海馬は地図か？記憶か？

  • 海馬＝地図（e.g., Successor Representation（SR），Clone-Structured Cognitive Graph（CSCG））：あらゆる地図を迅速に学習するが，その地図は般化しない。
  • 海馬＝記憶，皮質＝地図（e.g., Tolman–Eichenbaum Machine（TEM），Spatial Memory Pipeline（SMP））：皮質の地図を学習するのに時間がかかるが，一度学習すれば直ちに般化できる。
  • 海馬は両方の役割を時期によって使い分ける可能性。
    • 初めての経験：皮質に使える地図がまだないので海馬がその場で地図を作る。
    • 慣れた経験：皮質が構造を学び終えているので，海馬はその構造と中身を結ぶ記憶になる。
  • これにより，皮質が般化できる地図を学ぶ前から，海馬がその環境で使える状態空間を提供できる。海馬の地図はリプレイによってオフラインで皮質に送られ，皮質の学習を速める。しかも海馬の状態は脱エイリアス済みなので，生の観測よりも質の高い教師信号になる。
  • これは，TEMに海馬自身の遷移（海馬の状態から次の海馬の状態を予測する経路）を加えたモデルとして記述できる。

認知地図は行動にどう使われるか

  • RLの状態空間として使う（SR，Default Representation（DR; Piray & Daw, 2021））：SRやDRは，状態空間を受け取って価値を計算する。入力として，状態がきちんと区別された状態空間さえあればよいので，CSCGやTEMが作った海馬の状態をSRの入力にすることもできる。つまり，地図を作るモデルと地図を使うモデルは組み合わせられる。
  • 推論としての計画（planning as inference）：ツリーサーチの代わりに，開始状態とゴール状態を条件づけて，その間をつなぐactionとstateの系列の事後分布を推論する。HMMで両端を固定して中間を推定する操作と同じ。CSCGはベイズモデルなので，これを自然に実行できる。
  • ベクトルによる移動（格子コード）：ゴールの格子コードと現在地の格子コードから，進むべき方向のベクトルが直接出る。動物のような近道行動ができ，格子細胞は般化するので，方策も別の環境に移せる。
  • 遷移行列を固有分解すると，1ステップでも，nステップでも，SRでも，固有ベクトルは共通で，固有値の重みだけが違う。グリッド細胞が固有ベクトルを表しているなら，脳はその同じ基底を使って，固有値の重みを変えるだけでさまざまな多ステップの操作を実現できる。

Credit assignmentを価値関数ではなく状態表現を変えることで行う

  • 通常のRLでは状態空間は固定されていて，そこに価値を割り当てていくが，状態表現を変えて，価値を表しやすくすることもできる。
  • 新奇な課題では状態空間が素朴なので，線条体の古典的なRLで学ぶ。やがてゴールへの方策ができる。その行動系列を皮質・海馬系にリプレイし，統計を抽出して，より良い状態空間を学ぶ。その表現を線条体にRLの状態空間として返す。線条体はその表現のもとでより良い方策を学ぶ。皮質の表現が十分に良くなれば，新しい線条体のRLなしに，般化だけで行動を生成できる。
  • 行動の制御が状態空間の構成に帰着するなら，それを速く正確に行い，記憶に保存する必要がある。この効率を高めるなら，オフラインでやるべき。
  • 報酬を見つけたとき，その報酬との関係をすべての地点が知っている状態にしたい。そうすれば，どこにいても報酬に向かえる。リプレイによって，報酬地点から経路積分して離れていく。到達した各地点で，「ここからGへのベクトル」，つまり各地点用のGVCが決まる。そのGVCを，その地点の海馬・皮質の表現と結びつけて記憶に書き込む。これが海馬のランドマーク細胞の形成に当たるかもしれない。これを地点ごとに繰り返す。
  • その結果，状態そのものが報酬との関係を知っているので，ゴールの位置を保持し続ける必要がない。重い計算はオフラインで済み，オンラインでは記憶を引くだけ。

表現が因子分解されるかどうかは課題の構造で決まる

  • グリッドが報酬の方へ歪むことがある。因子分解された表現なら，歪んではいけない。空間表現は，報酬がどこにあっても同じであるべきだから。
  • 般化への圧力と単一の課題を正確に表現することとの間で生じる，「ワープ」と「非ワープ」の間の緊張関係を提案する。課題の切り替えがまれなら，般化の必要がないので課題専用の歪んだ表現でいい。切り替えが多いなら，般化で部品を組み替える方がいい。
  • つまり，課題の集合そのものが因子分解されていれば，細胞の表現も因子分解される。

Open questions

時間を認知地図にどう組み込むか

  • ここまでのモデルは，学習した表現が時間がたっても安定していることを前提にしていた。
  • しかし実際には，海馬などの表現は日をまたいでゆっくり入れ替わる（representational drift）。これは，記憶痕跡（エングラム）や受容野が固定されているという従来の考えと矛盾する。
  • では，表現を担う細胞が入れ替わっていくのに，なぜ空間の表現は安定して保たれるのか。
  • 般化モデルでは，海馬の細胞は複数の要素の結合（海馬の表現 ＝ 空間（MEC） × 感覚（LEC） × 時間（嗅内皮質の時間コード））。このうち時間コードだけがゆっくり進むと，結合が変わるので，海馬では別の細胞が使われるようになる。しかし新しい細胞は，時間の成分との結合が違うだけで，空間の成分との結合は前と同じ。したがって，空間の情報は保たれる。
  • つまり，ドリフトは感覚や空間ではなく時間が変わったことによるremappingだという解釈。

系列から認知の他の領域へ

  • 認知地図と無関係だった系列問題も同じように理解できるか。RNN・LSTM・Transformerのような系列学習器は，言語・数学・論理の問題でよい成績を出す。
  • 系列問題からの理解を系列でない認知領域にも広げられるか。

感想

  • 効率的な状態表現を抽出して利用することに関する計算論をゴリゴリに書き下していて非常に面白かった。
  • 特に，credit assignment問題を価値関数じゃなくて，状態表現を変えることで行うという発想は，目標・価値・構造を概念的に結びつけるものだし，それの神経回路も示されていて一番面白かった部分かも。
  • 前から考えていた，目標（ゴール）と行動の関係について示唆的な内容だった。いい状態表現とゴールが決まればそれでよくねってやつ。
  • そうなると，モデルベースなんて本当にやっているんだろうか。
  • 課題集合が因子分解されていれば，細胞の表現も因子分解されるというのは，メタ学習ともつながる。認知的機能のダイナミクスをボトムアップ的に説明しようという私のモチベにも合った。
  • この枠組みで，構造の学習するヒトとそうでないヒトの個体差をどのように説明できるだろうか。
